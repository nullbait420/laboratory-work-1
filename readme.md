### 1. Стандартный режим
Используется для обработки входного файла и записи результата.

```bash
python solution.py <входной_файл> <выходной_файл>
```

### 2. Режим бенчмарка (`--bench`)
Используется для тестирования производительности протокола.

```bash
python solution.py --bench [--seed 1] [--warmups 3] [--runs 10] [--dialect 3]
```

**Доступные флаги для бенчмарка:**
* `--bench` — запускает режим бенчмарка (обязательный флаг).
* `--seed` — начальное значение генератора (по умолчанию: `1`).
* `--warmups` — количество прогревочных запусков (по умолчанию: `3`).
* `--runs` — количество зачетных запусков (по умолчанию: `10`).
* `--dialect` — версия диалекта (по умолчанию: `3`).

**Пример:**
```bash
python solution.py --bench --seed 1 --warmups 3 --runs 10 --dialect 3
```
